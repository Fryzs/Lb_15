# Lb_15 — авторизація та ролі користувачів

Лабораторна робота №15 на Windows Forms (.NET).

## Що вміє

- **Вхід у систему** — окрема форма перевіряє логін і пароль за списком користувачів із файлу `User.TXT` і визначає роль (адміністратор або користувач).
- **Таблиця записів** — додавання, редагування та видалення рядків у `DataGridView`; дані вибраного рядка підставляються в поля вводу.
- **Керування користувачами** — форма зі списком облікових записів (логін, пароль, рівень доступу) з `User.TXT`.

## Запуск

Відкрийте `Lb_15.sln` у Visual Studio і натисніть F5. Поруч із виконуваним файлом має лежати `User.TXT` зі списком користувачів.
